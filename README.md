# web-study

Study tools for med school.

- **[`study-hub/`](study-hub/)** — the main project: a real-time, invite-only
  multi-user platform with shared subjects, live chat, collaborative notes,
  a mnemonics/resource vault, a Q-bank leaderboard, personal planner/pomodoro/
  calculators, and an admin panel. Run it with `cd study-hub && npm install
  && npm start`. See `study-hub/README.md` for setup and deployment.
- **`Foundation__Med_School_Toolkit.html`** — an earlier single-file,
  offline/local prototype of the same idea (localStorage-only, no accounts
  or collaboration).
- **`Recall__Flashcards.html`** — a standalone spaced-repetition flashcards
  app, linked to from Study Hub's Flashcards tab.
